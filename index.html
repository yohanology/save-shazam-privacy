Privacy Policy

Save Shazam to Spotify and SoundCloud · Last updated: November 2026

Overview

Save Shazam to Spotify and SoundCloud is a browser extension that adds Spotify and SoundCloud buttons to Shazam song pages. It is not affiliated with Shazam, Spotify or SoundCloud.

By default the buttons only open a search page on Spotify or SoundCloud in a new tab. No account connection and no data storage are involved.

Two optional modes can be turned on from the popup:

  • “Save straight to Liked Songs” connects your Spotify account to add tracks to your Liked Songs.
  • “Like the track automatically” clicks the Like button on the matching SoundCloud result, using the SoundCloud session already open in your browser.

Data Collection

What we collect

  • Nothing in the default mode.
  • Spotify OAuth tokens, only if you turn on the optional Liked Songs mode. They are used to save tracks to your Liked Songs and are stored locally in your browser.

What we do NOT collect

  • Personal information (name, email, etc.)
  • Browsing history
  • Shazam account information
  • Analytics or tracking data
  • No data is sent to servers owned by the extension author

Data Storage

Data is stored locally in your browser using Chrome's storage API (chrome.storage.local), and only when you use one of the optional modes:

  • Spotify access token
  • Spotify refresh token
  • Token expiry timestamp
  • Which Spotify mode is active
  • While you connect Spotify, a timestamp marking the request and, if the connection fails, its error message (both removed once the connection finishes or the popup shows the error)
  • Whether SoundCloud auto-like is on, and, for a few seconds while a SoundCloud tab loads, the title and artist of the track to like (in chrome.storage.session, cleared when the browser closes)

Data Usage

The track title and artist shown on the Shazam page are used to build the search. In the optional Liked Songs mode, your tokens are used exclusively to:

  • Search for the track with Spotify's API
  • Add it to your Spotify Liked Songs

Third-Party Services

Spotify

  • Default mode: we open open.spotify.com/search/<artist and title> in a new tab.
  • Optional Liked Songs mode: we use Spotify's official API to search and save tracks. Authentication uses OAuth 2.0 with PKCE (no client secret). The only permission requested is to modify your Liked Songs.
  • Spotify privacy policy

SoundCloud

  • Default mode: we only open a SoundCloud search page in a new tab.
  • Optional auto-like mode: in the search tab the extension opened, we read the results and click Like on the one that clearly matches the track. This uses your own SoundCloud session; the extension never sees your SoundCloud credentials and makes no API calls.
  • No data is sent to SoundCloud beyond the search and the Like click.

Shazam

  • We read the track title and artist from Shazam song pages you are viewing.
  • No data is sent to Shazam.

Data Sharing

We do not share, sell, or transfer your data to any third parties.

Data Deletion

To delete all stored data:

  • Click the extension icon and click “Disconnect and go back to search” and untick “Like the track automatically” (this also removes the optional permissions), or
  • Uninstall the extension — all local data is automatically removed.

Permissions Explained

Always requested:

  • storage — remember which Spotify mode you use and, in the optional mode, your Spotify tokens
  • https://www.shazam.com/song/* — add the buttons to Shazam song pages

Requested only when you turn on the Spotify Liked Songs mode:

  • identity — sign in to Spotify via chrome.identity.launchWebAuthFlow
  • https://accounts.spotify.com/* — Spotify sign-in
  • https://api.spotify.com/* — search and save tracks

Requested only when you turn on SoundCloud auto-like:

  • scripting and https://soundcloud.com/* — run the like script in the SoundCloud search tab the extension opened
